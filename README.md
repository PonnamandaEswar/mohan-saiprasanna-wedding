# Mohan & Sai Prasanna Wedding Invitation

A static, mobile-first invitation website. It needs no server or build step; GitHub Pages can host it directly.

## Publish with GitHub Pages

1. Sign in at GitHub and create a **public** repository named `mohan-saiprasanna-wedding`.
2. Put `index.html` at the repository root and upload the entire `images` folder beside it. Keep the paths and names unchanged, especially `images/couple-real-web.jpg` and `images/kalyanam.jpg`.
3. Commit the files to the `main` branch.
4. Open the repository's **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. After GitHub Pages finishes publishing, the site address will be `https://YOUR-GITHUB-USERNAME.github.io/mohan-saiprasanna-wedding/`.
6. Open that address on a phone to test it, then share the address with guests (for example, in WhatsApp).

A public GitHub repository and its Pages website are public, so the invitation and couple photo can be viewed by anyone who has the link (and the repository files are visible too).

## Guest features

The RSVP form opens WhatsApp with a message addressed to the family; the guest still needs to tap **Send**. Map, phone, calendar, and share buttons use the visitor's phone/browser. No RSVP information is stored by this website.
